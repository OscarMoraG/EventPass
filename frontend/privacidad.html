Política de privacidad

Última actualización: 13 de octubre de 2026

EventPass es un proyecto académico desarrollado por Oscar Mora para el programa de automatización con n8n de Campuslands. Esta página explica qué datos se usan en la aplicación y para qué.

Datos que se recopilan

  • Nombre y correo electrónico, cuando una persona se registra.
  • Contraseña: no se guarda en texto plano. Se almacena únicamente un resultado cifrado (hash con sal).
  • Datos de sesión (identificador, fecha de inicio y de expiración) cuando la persona inicia sesión.
  • Datos de las inscripciones a eventos: evento elegido, estado de la inscripción y fecha.

Para qué se usan

  • Crear la cuenta y permitir iniciar sesión.
  • Registrar inscripciones y controlar los cupos de cada evento.
  • Enviar correos de notificación relacionados con la inscripción, por ejemplo la confirmación.

Dónde se almacenan

Los datos se guardan en hojas de cálculo de Google Sheets y se procesan mediante flujos de automatización de n8n. El sitio web se publica en Vercel.

Uso de los servicios de Google

EventPass usa Google Sheets para almacenar datos y Gmail únicamente para enviar correos de notificación desde la cuenta del proyecto. La aplicación no lee, no busca y no analiza el contenido de las bandejas de correo de las personas que la usan. La información obtenida mediante los servicios de Google se usa solo para el funcionamiento descrito en esta página.

Con quién se comparten

Los datos no se venden ni se comparten con terceros con fines comerciales. Solo los procesan los servicios técnicos mencionados arriba (Google, n8n y Vercel) para que la aplicación funcione.

Conservación y eliminación

Los datos se conservan mientras dure el proyecto académico. Cualquier persona puede pedir que se elimine su información escribiendo al correo de contacto.
